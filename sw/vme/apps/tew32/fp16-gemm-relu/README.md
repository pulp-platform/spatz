# FP16 GeMM + bias + ReLU (O-POPE P5)

Kernels generated by `../../script/tf/gen_kernel.py` (`--bias 1`: gemm-relu, bias as one extra K-pair; `--bias 0`: matmul-relu). Staggered 2x1 blocks, ReLU on the VFU while the next block accumulates. `ubench*.c`: OPE/VFU port-sharing microbenchmarks (`script/ubench2.py`).

Build and run (from `hw/system/spatz_cluster`; the checks after the measured region can need more than 60 s):

```
(cd sw/build && cmake . && make test-vme-fp16-gemm-relu_C128_T64_O192 test-vme-fp16-matmul-relu_C128_T64_O192)
bin/spatz_cluster.vsim sw/build/vme/apps/test-vme-fp16-gemm-relu_C128_T64_O192
bin/spatz_cluster.vsim sw/build/vme/apps/test-vme-fp16-matmul-relu_C128_T64_O192
```

Results against O-POPE: `runtime/opope_summary.md` (repository root).
